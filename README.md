This Repository is for my Bachelor Thesis at Heidelberg University Germany

My Bachelor Thesis compares quality and readablity of Python-Code generated by three different LLMs, namely GPT5, DeepseekV3 and Gemma4. Using natural language input prompts, the LLMs were tasked to create code. A benchmark with 66 Leetcode tasks from the year 2026 was generated and the LLMs received the task description and Leetcode task syntax. The resulting program code was then checked for correctness, Pylint conformity and readability. Afterwards, the LLMs received one round of feedback regarding the quality of each program code over those metrics to imrpove their program code afterwards. Then each program code was again tested for correctness, Pylint confomity and readbility. The results were put into this Git-Repository. This approach is based on a paper by Liu et al. from 2024.
